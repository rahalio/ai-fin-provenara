# Provenara — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Art banker / lender

- As an art lender, I want a complete trust file before credit committee, so that LTV is based on evidenced title and custody—not a PDF pile.
- As an art lender, I want stale valuations to auto-expire for LTV, so that we do not finance on outdated marks.
- As an art lender, I want insurance status on the same screen as encumbrances, so that uninsured collateral cannot sneak through.

### Fractional platform operator

- As a platform operator, I want share subscriptions gated on KYC and eligibility, so that we do not onboard sanctioned or unsuitable investors.
- As a platform operator, I want distribution events recorded against the share register, so that we can prove investors were paid per terms.
- As a platform operator, I want alerts when cashflow patterns resemble undisclosed recycling, so that governance can intervene early.

### Registrar / provenance analyst

- As a registrar, I want to append provenance events with document hashes, so that history is append-only and disputable with evidence.
- As a registrar, I want custody inspection attestations that bind physical identity, so that registry entries cannot drift from the object.

### Compliance officer

- As a compliance officer, I want name-screening outcomes on all counterparties, so that high-value art flows meet AML expectations.
- As a compliance officer, I want need-to-know access to location data, so that theft risk is not amplified by oversharing.

### Insurer risk engineer

- As an insurer, I want to read custody and condition events, so that binding and claims postures reflect reality.
- As an insurer, I want to flag lapses back into the trust file, so that lenders and platforms see coverage gaps immediately.

### Investor servicing

- As investor servicing, I want a canonical share position and corporate-action-like notices, so that fractional holders are not managed via email threads.
